# Quick Start Guide

You've probably landed on this page because you're thinking about trying Linux but don't know where to start. Don't worry — I'll try to make it a little easier for you.

[[toc]]

## Where to Start?

As you probably know, there are multiple distributions to choose from. Here's a quick overview of the most beginner-friendly ones:

| Distribution | Based on | Stability | Software freshness | Best for |
|---|---|---|---|---|
| [Ubuntu](https://ubuntu.com) | Debian | ⭐⭐⭐⭐⭐ | Moderate | Absolute beginners |
| [Fedora](https://fedoraproject.org) | RHEL | ⭐⭐⭐⭐ | Very recent | Developers |
| [Linux Mint](https://linuxmint.com) | Ubuntu | ⭐⭐⭐⭐⭐ | Moderate | Windows switchers |
| [Arch Linux](https://archlinux.org) | — | ⭐⭐ | Bleeding edge | Advanced users |

::: tip New to Linux?
If you're coming from Windows, **Linux Mint** or **Ubuntu** are the safest bets. They have huge communities and tons of tutorials.
:::

::: warning Fedora note
Fedora ships very recent software which is great for developers, but it means some packages may be less battle-tested than on Ubuntu LTS.
:::
