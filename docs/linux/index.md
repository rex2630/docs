# Quick Start Guide

You've probably landed on this page because you're thinking about switching from Windows to Linux but don't know where to start. Don't worry — I'll try to make it as easy as possible.

[[toc]]

## Choosing Your Distribution

Think of a Linux distribution like a Windows edition — same core, different experience. Here's what we recommend for Windows switchers:

| Distribution | Stability | Software freshness | Best for |
|---|---|---|---|
| [Ubuntu](https://ubuntu.com) | ⭐⭐⭐⭐⭐ | Moderate | General beginners |
| [Linux Mint](https://linuxmint.com) | ⭐⭐⭐⭐⭐ | Moderate | Windows switchers |
| [Fedora](https://fedoraproject.org) | ⭐⭐⭐⭐ | Very recent | Gamers & developers |
| [Arch Linux](https://archlinux.org) | ⭐⭐ | Bleeding edge | Advanced users |

::: tip Not sure which to pick?
If you just want something that "works" out of the box and feels familiar, go with **Linux Mint**. It has a taskbar, start menu, and file manager that will feel right at home coming from Windows.

If you're a gamer, **Fedora** is a great choice — its up-to-date software means the latest GPU drivers, Proton updates, and gaming tools are available sooner.
:::

::: warning Arch Linux
Arch is not recommended for beginners. It requires manual setup and is best approached once you're already comfortable with Linux basics.
:::

## Installation

Installing Linux as a Windows user is easier than it sounds. The recommended way is to use a tool called **Rufus** — something you might already know from creating Windows install USBs.

### What You'll Need
- A USB drive with at least **8 GB** of free space
- The ISO file of your chosen distribution
- [Rufus](https://rufus.ie) (Windows app, free)

### Steps

1. Download the ISO of your chosen distro from its official website
2. Open Rufus, select your USB drive and the downloaded ISO
3. Click **Start** and wait for it to finish
4. Restart your PC and boot from the USB (usually **F12** or **F11** at startup)
5. Try Linux live from the USB first — no changes to your PC yet!
6. When you're ready, click **Install** from the live desktop

::: info Try before you install
Every major Linux distro lets you run fully from the USB without installing anything. This is called a **Live session** — perfect for testing if your hardware works before committing.
:::

::: details Dual boot vs. full switch
You don't have to replace Windows right away. During installation, you can choose to install Linux **alongside Windows** and pick which one to boot at startup. This is called dual booting and is a great way to ease into the switch.
:::

## First Steps After Install

Once you're up and running, here's what to do first:

1. **Update your system** — open the Update Manager or Software Center
2. **Install your browser** — Firefox is pre-installed, or grab Chrome from the app store
3. **Check your gaming setup** — if you're on Fedora, install [Steam](https://store.steampowered.com/about/) and enable **Proton** in settings to play Windows games
4. **Explore the app store** — most apps you know have Linux versions or good alternatives

::: tip Gaming on Linux
Steam's **Proton** compatibility layer lets you play a huge library of Windows-only games on Linux. Sites like [ProtonDB](https://www.protondb.com) let you check if your favourite games run well.
:::
