# Windows App Alternatives

Switching to Linux doesn't mean giving up your favourite apps. Most of what you use daily has a native Linux version or a great alternative.

::: warning How to correctly install software on Linux
On Linux, **always look for the app in your distribution's store first** (GNOME Software, Discover, or via terminal). Apps from the store update automatically alongside your system — you don't have to think about it.

Only if you can't find the app in the store should you download it from the official website.

Installing files from random websites is **not recommended** — just like on Windows, it can be a source of malware.
:::

::: info What about Photoshop?
Photoshop itself doesn't have a Linux version. GIMP covers most use cases, but if you need Photoshop specifically, it can sometimes run through **Wine** or a Windows VM. Check [WineHQ](https://appdb.winehq.org) for compatibility.
:::
