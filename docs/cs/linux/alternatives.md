# Alternativy k Windows aplikacím

Přechod na Linux neznamená vzdát se svých oblíbených aplikací. Většina toho, co denně používáš, má nativní linuxovou verzi nebo skvělou alternativu.

[[toc]]

## Prohlížeče

Tady nemusíš nic měnit — všechny hlavní prohlížeče jsou na Linuxu dostupné.

| Windows | Alternativa pro Linux | Poznámka |
|---|---|---|
| Chrome | [Chrome](https://www.google.com/chrome/) | Nativní linuxová verze |
| Firefox | [Firefox](https://www.mozilla.org/firefox/) | Předinstalovaný na většině distribucí |
| Edge | [Edge](https://www.microsoft.com/edge) | Nativní linuxová verze |
| Brave | [Brave](https://brave.com) | Nativní linuxová verze |

## Kancelář a produktivita

| Windows | Alternativa pro Linux | Poznámka |
|---|---|---|
| Microsoft Office | [LibreOffice](https://www.libreoffice.org) | Zdarma, otevírá .docx/.xlsx/.pptx soubory |
| Microsoft Office | [OnlyOffice](https://www.onlyoffice.com) | Vzhled bližší MS Office |
| Poznámkový blok | [Kate](https://kate-editor.org) / [gedit](https://gedit-technology.github.io) | Plnohodnotné textové editory |
| Notepad++ | [Kate](https://kate-editor.org) | Zvýraznění syntaxe, záložky |

::: tip Microsoft 365 v prohlížeči
Pokud hodně využíváš Word, Excel nebo PowerPoint, můžeš použít **Microsoft 365 online** na [office.com](https://www.office.com) — funguje perfektně v jakémkoliv linuxovém prohlížeči bez nutnosti instalace.
:::

## Grafika a design

| Windows | Alternativa pro Linux | Poznámka |
|---|---|---|
| Malování | [Pinta](https://www.pinta-project.com) | Jednoduchý editor obrázků |
| Photoshop | [GIMP](https://www.gimp.org) | Výkonný bezplatný editor obrázků |
| Illustrator | [Inkscape](https://inkscape.org) | Bezplatný editor vektorové grafiky |
| Lightroom | [Darktable](https://www.darktable.org) | Bezplatné zpracování fotek |

::: info A co Photoshop?
Photoshop nemá nativní linuxovou verzi. GIMP pokryje většinu případů použití, ale pokud Photoshop nezbytně potřebuješ, někdy může fungovat přes **Wine** nebo ve Windows VM. Kompatibilitu ověř na [WineHQ](https://appdb.winehq.org).
:::

## Hraní

| Windows | Alternativa pro Linux | Poznámka |
|---|---|---|
| Steam (Windows hry) | [Steam + Proton](https://store.steampowered.com) | Spustí většinu Windows her nativně |
| Epic Games | [Heroic Launcher](https://heroicgameslauncher.com) | Epic a GOG hry na Linuxu |
| GOG Galaxy | [Heroic Launcher](https://heroicgameslauncher.com) | Podpora GOG her zahrnuta |
| Xbox App | — | Není dostupné, použij Steam/Heroic |

::: tip Nejdřív ověř kompatibilitu
Před přechodem zkontroluj na [ProtonDB](https://www.protondb.com), jak dobře tvé hry na Linuxu běží. Většina populárních titulů funguje skvěle, zejména na Fedoře s aktuálními ovladači.
:::

## Systémové nástroje

| Windows | Alternativa pro Linux | Poznámka |
|---|---|---|
| Správce úloh | [GNOME Sledování systému](https://wiki.gnome.org/Apps/SystemMonitor) / `htop` | Vestavěný nebo terminálový |
| Ovládací panely | Nastavení GNOME / Nastavení systému KDE | Závisí na tvém desktopovém prostředí |
| Průzkumník | Nautilus / Dolphin / Thunar | Závisí na tvém desktopovém prostředí |
| 7-Zip | [File Roller](https://wiki.gnome.org/Apps/FileRoller) / [PeaZip](https://peazip.github.io) | Správci archivů |
| WinRAR | [PeaZip](https://peazip.github.io) | Zdarma, podporuje extrakci RAR |
