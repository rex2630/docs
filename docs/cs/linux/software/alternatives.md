# Alternativy k Windows aplikacím

Přechod na Linux neznamená vzdát se svých oblíbených aplikací. Většina toho, co denně používáš, má nativní linuxovou verzi nebo skvělou alternativu.

::: warning Jak správně instalovat software na Linuxu
Na Linuxu **vždy nejdříve hledej aplikaci v obchodě své distribuce** (GNOME Software, Discover, nebo příkazem v terminálu). Aplikace ze storu se automaticky aktualizují spolu se systémem — nemusíš na to myslet.

Teprve pokud aplikaci ve storu nenajdeš, stáhni ji z oficiálních stránek.

Instalace souborů z náhodných stránek na internetu se **nedoporučuje** — stejně jako na Windows může být zdrojem malwaru.
:::
