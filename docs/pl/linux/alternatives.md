# Alternatywy dla aplikacji Windows

Przejście na Linuxa nie oznacza rezygnacji z ulubionych aplikacji. Większość tego, czego używasz na co dzień, ma natywną wersję na Linuxa lub świetną alternatywę.

::: warning Jak poprawnie instalować oprogramowanie na Linuxie
Na Linuxie **zawsze najpierw szukaj aplikacji w sklepie swojej dystrybucji** (GNOME Software, Discover lub przez terminal). Aplikacje ze sklepu aktualizują się automatycznie razem z systemem — nie musisz się o to martwić.

Tylko jeśli nie możesz znaleźć aplikacji w sklepie, pobierz ją z oficjalnej strony.

Instalowanie plików z przypadkowych stron **nie jest zalecane** — tak samo jak na Windows, może być źródłem złośliwego oprogramowania.
:::

:::
